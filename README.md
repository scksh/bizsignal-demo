# BizSignal 프로토타입

공공 IT, 소프트웨어 용역의 공고 탐색, 시장 분석과 근거 탐색을 시연하는 웹 프로토타입입니다.

**[웹사이트 열기](https://scksh.github.io/bizsignal-demo/)**

## 시연 범위

- 가상 공고와 과거 사업 데이터로 동작합니다.
- 실제 API, 인증, 알림 발송, AI 모델은 연결하지 않았습니다.
- 프로필, 북마크와 검토 상태는 각 사용자의 브라우저에 저장됩니다.
- `index.html`에는 화면에 필요한 CSS, JavaScript와 가상 데이터가 포함되어 있습니다.

## 배포

GitHub Pages가 `main` 브랜치의 루트(`/`)를 게시합니다. `index.html`을 변경해 푸시하면 자동 반영됩니다. `.nojekyll`은 정적 파일을 그대로 제공하도록 설정합니다.

이 저장소에는 배포용 HTML과 안내 문서만 보관합니다.
