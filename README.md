# BizSignal 프로토타입

공공 IT와 소프트웨어 용역의 공고 탐색, 조달 단계, 시장 분석과 근거 탐색을 시연하는 웹 프로토타입입니다.

**[웹사이트 열기](https://scksh.github.io/bizsignal-demo/)**

## Preview 0.2

- 첫 화면에서 **ERP 공고 상세**를 열면 발주계획, 사전규격, 입찰공고, 개찰·낙찰, 계약을 단계별로 확인할 수 있습니다. 상태와 출처는 2026년 11월 18일 08:00 KST 기준으로 정리한 공개 자료 스냅숏입니다.
- **참여 전에 확인하세요**에서 나라장터 공고문 조항을 열 수 있습니다. **과거 사례**에서는 같은 기관의 별개 용역에 대한 공개 낙찰 및 계약 경로를 2D·3D로 봅니다. 공개 집계상 관계는 점선으로 표시하며 공식 계약 식별키는 미확인입니다.
- 기존 가상 공고와 시장 분석 시연을 함께 제공합니다. 실제 공고 샘플 두 건은 가상 계약금액 집계와 분리합니다.
- 프로필, 북마크와 검토 상태는 각 사용자의 브라우저에 저장됩니다. 검색과 그래프 답변은 로컬 데이터로 실행하며 실시간 API, Neptune, 인증, 알림 발송, LLM 연동은 본 구축에 해당합니다.

공개 자료 출처는 각 단계와 답변 근거에서 열 수 있습니다. 참가조건과 최신 정정은 나라장터 공고문에서 확인하세요.

## 배포

GitHub Pages가 `main` 브랜치의 루트(`/`)를 게시합니다. `index.html`을 변경해 푸시하면 자동 반영됩니다. `.nojekyll`은 정적 파일을 그대로 제공하도록 설정합니다.

이 저장소에는 단독 실행이 가능한 `index.html`과 안내 문서만 보관합니다. HTML 안에 스타일, 공개 샘플 및 가상 데이터, 브라우저 모듈이 포함됩니다.
